# Homebrew Tap

Personal [Homebrew](https://brew.sh) tap for tools by [anjuls](https://github.com/anjuls).

## Usage

```bash
brew tap anjuls/tap
brew install <formula>
```

## Formulas

| Formula | Description |
|---------|-------------|
| [`cloudinary-cli`](Formula/cloudinary-cli.rb) | Optimize images locally to WebP/AVIF and upload to Cloudinary |
